# Coding With AI
Source: AI Learning Portal educational content
Topics: debugging, code review, security, testing.

AI coding tools may generate code that appears plausible but contains bugs, insecure patterns, outdated APIs, or assumptions that do not match the project. Treat generated code as a draft, not as a trusted authority.

When asking for coding help, include the language, relevant code, the exact error message, expected behavior, actual behavior, and constraints. Remove API keys, passwords, tokens, private URLs, and personal data before sharing code.

Review generated code line by line. Run it in a safe test environment, test normal and edge cases, check dependencies and licensing, and understand what the code does before using it. Never run commands from an AI response blindly, especially commands that delete files, change permissions, install unknown software, or transmit data.

For debugging, describe the smallest reproducible problem. Ask the assistant to explain the likely cause, suggest a minimal fix, and provide a test that demonstrates the fix. Confirm the fix works in your actual environment.
