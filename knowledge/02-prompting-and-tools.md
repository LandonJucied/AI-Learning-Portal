# AI Tools and Prompting
Source: AI Learning Portal educational content
Topics: prompt engineering, chatbots, writing assistance, research, coding, verification.

A prompt is the instruction or input supplied to an AI system. A strong prompt usually specifies the task, context, audience, constraints, and desired output format. It may also include examples and explain what a good result should achieve.

Weak prompt: “Tell me about AI.” More useful prompt: “Explain machine learning to a Grade 9 student in five bullet points, define two key terms, include one everyday example, and mention one limitation.” The second prompt makes the goal, audience, format, and content requirements clearer.

Prompt iteration is a normal workflow: define the goal; give context and constraints; review the response; identify missing or inaccurate parts; refine the prompt; verify the result. A better prompt can improve relevance but cannot guarantee truth.

AI chatbots can explain concepts, brainstorm, summarize provided text, and help organize work. Writing tools can help with outlines or clarity where permitted. Image-generation tools produce images from instructions. Coding assistants can explain code, suggest examples, and help debug, but generated code must be reviewed and tested.

For research, use AI to identify questions or starting points, then verify important claims using reliable original sources. Do not trust citations merely because a model presents them. Check that a source exists and supports the claim. AI can produce hallucinations: fluent-sounding but false or unsupported content.

Do not paste passwords, private records, confidential school or workplace information, or personal data into an AI tool unless the service and the relevant authority explicitly permit it. Follow classroom rules and disclose AI assistance when required.
