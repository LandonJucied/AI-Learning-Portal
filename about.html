ABOUT THE PROJECT

Built to Make AI Understandable.

An interactive educational experience centered on understanding AI, using AI tools effectively, and practicing responsible AI use.

THE GOAL

Learn AI. Use AI. Understand AI.

The portal is designed as a learning platform rather than a collection of static information. Lessons connect to challenges, progress, XP, and achievements.

THE AUDIENCE

High School Students

The experience is written for high school learners and uses short explanations, examples, activities, and practical scenarios.

THE STRUCTURE

Three Core Modules

AI Fundamentals introduces concepts. Using AI Tools develops practical skills. AI Ethics & Responsibility focuses on responsible use.

THE EXPERIENCE

Feedback at Every Step

Each activity provides a clear result, explains why an answer works, and records verified milestones so students can see what to work on next.

IMPLEMENTATION

Built with a simple, transparent stack.

The site uses browser-native technologies so its structure can be inspected, tested, and maintained without a framework or build step.

01 / STRUCTURE

HTML

Semantic sections, labeled controls, navigation landmarks, and clear page hierarchy.

02 / PRESENTATION

CSS

A shared visual system for layout, responsive behavior, accessible focus states, and reduced motion.

03 / INTERACTION

JavaScript

Assessment scoring, checkpoint gates, prompt building, accessibility settings, XP, and badges.

04 / PERSISTENCE

Browser storage

Progress and accessibility preferences are stored locally on the device. No account is required.

DESIGN PRINCIPLES

Advanced visuals with a clear purpose.

The interface uses a consistent dark visual system, strong contrast, reusable cards, responsive layouts, and restrained motion to make complex information easier to navigate.

01

Consistency

Shared navigation, buttons, typography, and spacing across pages.

02

Accessibility

Keyboard support, visible focus, text-size controls, contrast settings, and reduced motion.

03

Feedback

Quiz responses, XP notices, completion states, and saved progress.

04

Transparency

Resources and attribution help readers investigate the information presented.
